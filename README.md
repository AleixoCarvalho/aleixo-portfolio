# Aleixo Portfolio

**Live site:** https://aleixocarvalho.github.io/aleixo-portfolio/

A professional black-and-white portfolio website where clients can register and book an appointment.

## Pages

| Page | What it does |
|---|---|
| [Home](https://aleixocarvalho.github.io/aleixo-portfolio/) | Landing page with an interactive "anti-gravity" background: shapes float upwards, link together and move away from the cursor |
| [Register](https://aleixocarvalho.github.io/aleixo-portfolio/register.html) | Client sign-up form with validation |
| [Book](https://aleixocarvalho.github.io/aleixo-portfolio/booking.html) | Appointment booking: type, format, weekday-only date picker and time slots |

## Features

- Fully responsive, with a mobile menu
- Custom HTML5 canvas animation written in vanilla JavaScript (no libraries)
- Form submissions saved to a database through **Skybase**, a database app I built, with an email copy as backup
- Respects "reduce motion" accessibility settings
- Hosted for free on GitHub Pages

## Built with

HTML · CSS · JavaScript · GitHub Pages · Skybase
